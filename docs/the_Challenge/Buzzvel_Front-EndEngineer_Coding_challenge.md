## Frontend Engineer Coding challenge

### The challenge

Build **one complete responsive page for desktop and mobile** from the supplied Figma design using **Next.js App Router, TypeScript and Tailwind CSS**.

[Open the Buzzvel FE Test 2026 design.](https://www.figma.com/design/G0zSf6gyynwzEusOCgm2CM/Buzzvel-FE---Test-2026?t=cCNzbZx4x5KF18Gp-0)

**All sections shown in the desktop and mobile designs are required.** If a layout or behavior is unclear, make a reasonable choice and explain it briefly in your README. Contact Buzzvel if you cannot access the design.

### What we expect

- Match the design closely, including typography, spacing and imagery.
- Make the page work on mobile, tablet and desktop.
- Write clear, reusable components with typed props.
- Implement the interactions shown in the design. Use local or mock data; backend and CMS setup are not required.
- Use semantic HTML, keyboard-friendly controls, image descriptions and appropriate page metadata.
- Keep images, fonts and page loading efficient. Any animations should respect reduced-motion preferences.

Keep the implementation focused. Storybook or a small automated test is welcome, but optional.

### AI tools

AI tools are allowed. Briefly mention how you used them and how you checked the result. You should be able to explain the code you submit.

### What to submit

Create a **public GitHub repository** containing your source code and a short **README in English** covering:

- How to install, run and build the project.
- Key decisions, known gaps and approximate time spent.
- Any AI tools used.

Check the page on mobile and desktop and run a production build before submitting. Disclose any failing checks or known issues.

Submit the public repository link through the [Buzzvel test submission form](https://forms.clickup.com/6647387/f/6avjv-18455/PLUYAZ40HA3XTQOEFW) by the deadline above. A live preview or Lighthouse screenshot is optional.

### How we evaluate

We will review design accuracy, responsiveness, code quality, working interactions, accessibility and performance. Clear decisions and attention to detail matter.

We may invite you to a technical conversation to walk through your solution.
